# Contributing to TraceKit

Thank you for your interest in TraceKit!

## Current Status

**Note: TraceKit is currently NOT accepting external Pull Requests.**

We are focused on reaching a stable `v1.0` release. To maintain tight architectural control during this early phase, we are restricting contributions. 

However, since TraceKit is licensed under the MIT License, you are completely free to fork the repository, study the codebase, and adapt it for your own learning or projects.

## Reporting Bugs

If you find a bug, please help us by opening an issue on GitHub:
1. Check the [existing issues](https://github.com/nelomr/trace-kit/issues) to ensure it hasn't already been reported.
2. Open a new issue using the "Bug Report" template if available, or just provide a clear description.
3. Include reproduction steps, environment details (OS, browser, node version), and expected behavior.

## Suggesting Features

We welcome feature requests and ideas:
1. Check the [existing issues](https://github.com/nelomr/trace-kit/issues) to see if someone else has already suggested it.
2. Open a new issue detailing your feature idea, use case, and how it aligns with the goals of TraceKit.

## Future Contributions

Once TraceKit reaches a stable `v1.0` release, we will open the project to external contributors. At that point, this document will be updated with full guidelines on setting up the development environment, writing tests, and submitting PRs.

Thank you for understanding!
